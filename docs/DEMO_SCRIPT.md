# Demo script

Target length: two to three minutes. Use the synthetic demo workspace only.

## 1. Establish the problem — 0:00–0:20

Open GenForge and show the line: “Make every career claim defensible.” Explain
that the product turns scattered candidate evidence into a targeted resume with
the proof trail still attached.

## 2. Candidate and disclosure — 0:20–0:45

Load the synthetic workspace. Show the candidate facts and synthetic source
cards. Open the privacy disclosure and point out the fields, source context,
local storage boundary, and the fact that no applications are submitted.

## 3. Live evidence run — 0:45–1:20

Accept the disclosure and start the live run. Show the Inspector activity events:
source extraction, model selection, evidence analysis, and target-job analysis.
Do not show chain-of-thought or raw provider transcripts.

## 4. Proof and coverage — 1:20–1:55

Open Evidence, select a claim, and approve one claim. Reject or request
confirmation for another. Open Target Job and show that the score is labeled
reviewed evidence coverage, not hiring probability.

## 5. Resume and export — 1:55–2:35

Generate ATS Classic, select a bullet, and show its claim/source trail in proof
mode. Edit a bullet, open Export, run the checks, and download the synthetic PDF.
Briefly mention DOCX, Markdown, and text exports.

## 6. Trust close — 2:35–2:55

Reload the workspace to show persistence. Close with the limitation: GenForge
does not apply to jobs, scrape LinkedIn, store credentials, or replace user
review with a model confidence score.
