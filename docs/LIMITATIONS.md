# Limitations

- GenForge is local-only and does not provide a hosted multi-user service.
- A user must install Pi and supply their own OpenCode Zen key for live runs.
- Model availability, quotas, latency, and image support depend on the
  configured provider account.
- Public research may fail because a site blocks automated access, requires
  authentication, or changes its markup. GenForge shows a recoverable error and
  does not invent a result.
- LinkedIn is not scraped. Use an export or screenshot supplied by the user.
- Match coverage is evidence coverage, not a hiring prediction.
- The app does not submit applications, store credentials, or bypass CAPTCHAs.
- The demo fixture is synthetic. Its real Pi output is not a replayed fixture.
